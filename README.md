# Happy Nameday, Celine! 💗

A small romantic static website with a photo and floating-heart animation.

## Preview locally
Open `index.html` in your browser. Keep the `assets` folder next to it so the photo loads.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `happy-nameday-celine`).
2. Upload `index.html` and the `assets` folder to the repository's root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. After GitHub finishes publishing, it will show your website URL in the Pages section.

The page is static and does not need a build step.
